    Estructures de Repetició

    3. Estructures de Repetició (C3.2)

    Objectius

    • Comprendre els bucles for i while per repetir un bloc de codi diverses vegades.
    • Dominar l'ús de break i continue per gestionar el flux dins dels bucles.

    Continguts

    Bucle while

    El bucle while permet repetir un bloc de codi mentre una condició sigui certa. El bucle continua fins que la condició avaluada sigui falsa.

    Sintaxi i ús

    La sintaxi del bucle while és la següent:

    while condicio:
    # codi a repetir
    • condicio: És l'expressió booleana que s'avaluarà abans de cada iteració.
    • El bucle s'executa mentre la condició sigui True. Quan esdevingui False, el bucle s'atura.
    Exemple bàsic de bucle while:
    contador = 0

while contador < 5:
    print(contador)
    contador += 1

    En aquest exemple, el bucle imprimeix els números del 0 al 4. La condició és contador < 5, així que el bucle continuarà fins que contador arribi a 5.

    Ús de break i continue en un bucle while
    • break: S'utilitza per sortir immediatament d'un bucle.
    • continue: Salta a la següent iteració del bucle, saltant el codi que es troba després de la instrucció continue.

    Exemple amb break:

    contador = 0

while contador < 5:
    if contador == 3:
        break  # Surt del bucle quan el contador arriba a 3
    print(contador)
    contador += 1

    En aquest exemple, el bucle imprimeix 0, 1 i 2 i es deté quan contador arriba a 3.

    Exemple amb continue:

    contador = 0

while contador < 5:
    contador += 1
    if contador == 3:
        continue  # Salta aquesta iteració quan el contador és igual a 3
    print(contador)

    En aquest exemple, el número 3 no es mostrarà, ja que s'omet en la iteració on es troba.

    Bucle for

    El bucle for s'utilitza per iterar sobre una seqüència (com una llista, una cadena de text o un rang de valors).

    Sintaxi i ús

    La sintaxi del bucle for és la següent:

    for variable in seqüència:
    # codi a repetir
    • variable: La variable que pren el valor de cada element de la seqüència en cada iteració.
    • seqüència: La seqüència de valors sobre la qual es vol iterar (pot ser una llista, un string, un conjunt, un diccionari, etc.).
    Exemple de bucle for amb range()
    for i in range(5):
    print(i)

    Aquest codi imprimeix els números de 0 a 4. El range(5) crea una seqüència de números de 0 fins a 4.

    Ús de break i continue en un bucle for

    Exemple amb break:

    for i in range(10):
    if i == 5:
        break  # Surt del bucle quan i és igual a 5
    print(i)

    Exemple amb continue:

    for i in range(5):
    if i == 2:
        continue  # Salta aquesta iteració quan i és igual a 2
    print(i)

    Activitats

    1. Exercici pràctic amb while: Crea un programa que sume els primers 10 números enters utilitzant un bucle while.
    2. Exercici pràctic amb for: Crea un programa que imprimisca els quadrats dels números de l'1 al 5 utilitzant un bucle for.
    3. Exercici amb break i continue: Crea un programa que imprimisca els números de l'1 al 10, però que ometa el número 5 i isca del bucle quan el número 8 siga trobat.
