    Introducció

    1. Introducció a les Estructures de Control i Depuració

    Què són les estructures de control i la depuració?

    Les estructures de control són fonamentals per a qualsevol llenguatge de programació. Permeten al programador dirigir el flux d'execució del codi, decidint quines instruccions s'han d'executar en funció de certes condicions, repetint accions múltiples vegades o saltant parts del codi en moments determinats.

    Les estructures de control s'agrupen en: - Estructures de selecció: Permeten triar quines accions realitzar segons una condició (per exemple, if, else). - Estructures de repetició: Permeten repetir una o més instruccions de manera indefinida o fins que es compleixi una condició (per exemple, bucles for, while). - Estructures de salt: Permeten interrompre o modificar el flux d'execució del codi (per exemple, break, continue).

    La depuració és el procés d'identificar i corregir errors en el codi (també coneguts com a bugs). Un cop es detecta un error en el codi, és necessari depurar-lo per evitar que el programa es detingui inesperadament. La depuració inclou tècniques com l'ús de missatges de depuració, el seguiment del flux del programa i l'ús d'eines especialitzades.

    Breu història de les estructures de control i la depuració

    • Anys 1950-1960: Amb els primers llenguatges de programació com Fortran i COBOL, es van començar a utilitzar estructures de control bàsiques com els salts (goto) i les condicions (if).
    • Anys 1970-1980: Els llenguatges com C van introduir noves estructures de control més sofisticades i més fàcils d'utilitzar. A la vegada, van aparèixer tècniques de depuració amb les primeres eines d'anàlisi de codi.
    • Anys 1990-2000: Amb el creixement de la programació orientada a objectes i l'ús de Java i C++, les estructures de control van evolucionar, i la depuració va incorporar noves tècniques, incloent el seguiment de codi en temps real.
    • Actualitat: Els llenguatges moderns com Python, JavaScript o Go han millorat les estructures de control i les tècniques de depuració, afegint eines com depuradors interactius i entorns de desenvolupament integrats (IDE) que ajuden a escriure codi més eficaç i detectar errors més fàcilment.

    Tipus d'estructures de control

    Les estructures de control en programació es poden classificar en diverses categories. Les més comunes són les estructures de selecció, estructures de repetició i estructures de salt.

    Estructures de selecció

    Les estructures de selecció permeten que el programa prengui decisions en funció d’una condició. Les més comunes són les condicions if, elif i else. Aquestes estructures s’utilitzen per executar codi diferent segons es compleixin o no certes condicions.

    Exemple: 

    if condicio:
    # fer alguna cosa
else:
    # fer alguna altra cosa

    Estructures de repetició

    Les estructures de repetició permeten repetir una o més instruccions fins que es compleixi una condició. Les més comunes són els bucles for i while.

    Exemple de bucle while: 

    while condicio:
    # repetir alguna cosa

    Estructures de salt

    Les estructures de salt permeten modificar el flux d'execució normal del programa. Les sentències com break, continue i pass són molt útils en bucles i condicions.

    • break: Sortir d'un bucle de manera anticipada.
    • continue: Saltar a la següent iteració del bucle.
    • pass: No fer res, es fa servir com a marcador.

    Què és la depuració?

    La depuració és el procés de trobar i solucionar els errors o bugs en un programa. Tots els programes contenen errors durant el seu desenvolupament, i la depuració permet identificar els punts on el programa no es comporta com s'esperava.

    Tècniques de depuració:

    • Missatges de depuració: Imprimir missatges en el codi per veure quines parts del codi s'executen.
    • Depuradors interactius: Eines que permeten analitzar el flux d'execució línia per línia i examinar les variables durant l'execució.

    Conclusions

    En aquesta unitat, aprendrem a utilitzar les estructures de control bàsiques per escriure programes que siguin dinàmics i eficaços. També ens centrarem en les tècniques de depuració per identificar i corregir errors, i la documentació del codi per garantir que el nostre programari sigui fàcil de mantenir i entendre per altres programadors.
