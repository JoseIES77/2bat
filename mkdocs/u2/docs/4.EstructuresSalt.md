## Continguts

### **Estructures de salt**

Les estructures de salt permeten modificar el flux normal d'execució del codi dins dels bucles o condicions. Les sentències de salt més utilitzades són:

- **`break`**: S'utilitza per sortir d'un bucle de manera anticipada, independentment de si s'ha completat tota la iteració.

  **Exemple amb `break`:**
  ```python
  for i in range(10):
      if i == 5:
          break  # Sortir del bucle quan i és igual a 5
      print(i)
  ```

- **`continue`**: S'utilitza per saltar la iteració actual del bucle i continuar amb la següent. No executa el codi que es troba després de la instrucció `continue` per a la iteració en curs.

  **Exemple amb `continue`:**
  ```python
  for i in range(10):
      if i == 5:
          continue  # Salta aquesta iteració quan i és igual a 5
      print(i)
  ```

- **`pass`**: S'utilitza com a marcador de codi pendent. No fa res, però s'usa per mantenir la sintaxi quan es necessita que el codi estigui completament estructurat, però no es vol implementar res en aquell moment.

  **Exemple amb `pass`:**
  ```python
  for i in range(10):
      if i == 5:
          pass  # No fa res quan i és igual a 5
      print(i)
  ```

### **Exemples pràctics**

A continuació, es mostren exemples pràctics que utilitzen les sentències de salt per gestionar el flux dels bucles.

1. **Exemple amb `break` i `continue`:** Crea un programa que sumi els primers números fins a trobar el primer número negatiu. Utilitza `break` per sortir del bucle quan es trobi un número negatiu.

   **Exemple de codi:**
   ```python
   suma = 0
   while True:
       num = int(input("Introdueix un número: "))
       if num < 0:
           break  # Sortir del bucle quan es trobi un número negatiu
       suma += num
   print("La suma dels números introduïts és:", suma)
   ```

2. **Exemple amb `continue`:** Crea un programa que imprimeixi els números de l'1 al 10, però salti el número 5 utilitzant `continue`.

   **Exemple de codi:**
   ```python
   for i in range(1, 11):
       if i == 5:
           continue  # Salta la iteració quan i és igual a 5
       print(i)
   ```

3. **Menú de selecció amb continue i break**

Un menú de selecció pot ser gestionat utilitzant les sentències continue i break dins d'un bucle. A continuació, veurem com implementar aquest tipus de menú utilitzant ambdues opcions.

### Menú amb continue

L'ús de continue permet seguir demanant opcions fins que l'usuari triï una opció vàlida, saltant les opcions incorrectes.

Exemple de codi amb continue:

```python

while True:
    print("Menú de selecció:")
    print("1. Opción 1")
    print("2. Opción 2")
    print("3. Sortir")
    
    opcio = input("Selecciona una opció: ")

    if opcio == "1":
        print("Has seleccionat l'Opció 1.")
    elif opcio == "2":
        print("Has seleccionat l'Opció 2.")
    elif opcio == "3":
        print("Sortint del menú...")
        break  # Sortir del bucle si l'usuari selecciona l'opció de sortir
    else:
        print("Opció incorrecta. Torna a intentar-ho.")
        continue  # Torna al principi del bucle per demanar una nova opció


```

### Menú amb break

En aquest cas, el bucle continuarà fins que l'usuari introdueixi l'opció 0 per sortir. Si l'usuari no prem la 0, el programa seguirà executant-se, permetent al mateix temps l'ús de la sentència break per sortir en qualsevol moment si l'usuari tria aquesta opció.

Exemple de codi amb break:

```python

while True:
    print("Menú de selecció:")
    print("1. Opción 1")
    print("2. Opción 2")
    print("0. Sortir")
    
    opcio = input("Selecciona una opció: ")

    if opcio == "1":
        print("Has seleccionat l'Opció 1.")
    elif opcio == "2":
        print("Has seleccionat l'Opció 2.")
    elif opcio == "0":
        print("Sortint del menú...")
        break  # Sortir del bucle quan l'usuari introdueix 0
    else:
        print("Opció incorrecta. Torna a intentar-ho.")


```
