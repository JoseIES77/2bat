## Continguts

### **Condicions amb `if` i `else`**

Les estructures de control de selecció permeten que el programa prenga decisions en funció de certes condicions. A Python, les estructures de selecció més comunes són `if`, `elif` i `else`.

#### **Com avaluar condicions simples**

Les condicions es poden avaluar utilitzant operadors lògics com `==`, `>`, `<`, `>=`, `<=`, `!=`. Quan una condició es compleix, s'executa el bloc de codi associat.

**Exemple bàsic: Verificació si un número és positiu o negatiu**

```python
num = int(input("Introdueix un número: "))

if num > 0:
    print("El número és positiu.")
else:
    print("El número és negatiu o zero.")
```

En aquest exemple, el programa demana un número a l'usuari i, en funció de si el número és positiu o no, imprimeix un missatge adequat.

#### **Sintaxi**

La sintaxi per a les condicions `if` i `else` en Python és la següent:

```python
if condicio:
    # codi si la condició és certa
else:
    # codi si la condició és falsa
```

- **`if`**: Comprova si una condició és certa.
- **`else`**: S'executa quan la condició de l'`if` no es compleix.

### **Condicions amb `elif`**

Quan tenim més d'una condició a avaluar, podem utilitzar **`elif`** (sinó, si) per comprovar condicions addicionals. Això permet evitar estructures de selecció llargues amb diversos `if` independents.

**Exemple amb `elif`:**

```python
num = int(input("Introdueix un número: "))

if num > 0:
    print("El número és positiu.")
elif num == 0:
    print("El número és zero.")
else:
    print("El número és negatiu.")
```

En aquest exemple, el programa fa una comprovació addicional per verificar si el número és zero, a més de la comprovació de si és positiu o negatiu.

#### **Sintaxi de `elif`**

La sintaxi és la següent:

```python
if condicio1:
    # codi si la condició 1 és certa
elif condicio2:
    # codi si la condició 2 és certa
else:
    # codi si cap de les condicions anteriors es compleix
```

### **Operadors lògics**

Els operadors lògics permeten combinar múltiples condicions per a realitzar decisions més complexes:

- **`and`**: La condició serà certa només si totes les condicions són certes.
- **`or`**: La condició serà certa si almenys una de les condicions és certa.
- **`not`**: Inverteix el resultat d'una condició.

**Exemple amb operadors lògics:**

```python
edad = int(input("Introdueix la teva edat: "))
si_te_pase = input("Tens permís per passar (sí/no)? ")

if edad >= 18 and si_te_pase == "sí":
    print("Pots passar.")
else:
    print("No pots passar.")
```

En aquest exemple, la persona pot passar només si té 18 anys o més **i** té permís.
