### Traça de programes

11. Què mostrarà aquest programa en **Python**?
    ```python
    x = 3
    y = 2
    print(x + y * 2)
    ```

12. Què s’imprimirà en aquest fragment?
    ```python
    for i in range(1, 4):
        print(i)
    ```

13. Què contindrà la llista `L` al final?
    ```python
    L = []
    for i in range(3):
        L.append(i * 2)
    ```

14. Què mostrarà el programa següent?
    ```python
    x = 5
    if x > 10:
        print("Gran")
    else:
        print("Menut")
    ```

15. Escriu el resultat de la següent traça en **pseudocodi**:
    ```
    suma = 0
    per i de 1 fins a 4
        suma = suma + i
    fi
    escriure suma
    ```
